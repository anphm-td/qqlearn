# Thêm layout desktop cho "Sổ học TOEIC" rồi chạy lại workflow build

## Mục tiêu
App dùng tốt trên máy tính: ở màn hình ≥768px có **sidebar trái thay bottom tab bar**, Sổ từ vựng/Sổ lỗi sai/Thống kê dạng **2 cột (danh sách + chi tiết)**, thêm **phím tắt cơ bản**. Mobile (<768px) giữ nguyên đúng design system hiện có. Sau khi plan được duyệt: cập nhật tài liệu thiết kế → sửa workflow build → khởi động lại run.

## 1. Bổ sung design system — `.superdesign/design-system.md`
Append thêm "Mục 10 — Layout desktop (≥768px)" (không đụng nội dung cũ), nội dung bám đúng aesthetic phiếu trả lời TOEIC đã có:
- **Sidebar trái cố định ~220px**: 4 mục tab chính (Hôm nay · Học · Sổ tay · Thống kê) + đường kẻ section + link phụ (Tro chuyện, Cài đặt). Nền `--paper`, viền phải 1px `--rule`, mục active = bubble tô mực `--ink`, icon line 1.5px như mobile.
- **Home 2 cột** (tổng rộng tối đa ~960px căn giữa): cột trái — vòng ProgressBubble + streak tuần + nút Bắt đầu học; cột phải — danh sách buổi học + ghi chú cuối ngày.
- **Sổ từ vựng & Sổ lỗi sai: master-detail 2 cột** — danh sách trái ~340px (kèm ô tìm kiếm), chi tiết bên phải; mobile giữ nguyên luồng điều hướng sang trang chi tiết.
- **Thống kê**: lưới 2 cột cho các biểu đồ (giờ học | phân bổ Part), heatmap và báo cáo tuần full-width.
- **Chat (Tro chuyện), Onboarding, Cài đặt**: cột giữa hẹp 480–720px (nội dung dạng đọc/form đọc tốt nhất khi hẹp).
- **Phím tắt**: `1`–`4` đổi tab, `N` = mở ghi chú hôm nay — tự bỏ qua khi focus đang nằm trong input/textarea; gợi ý phím tắt hiển thị ở chân sidebar.
- **Không thêm màu/font mới** — mọi thứ vẫn qua tokens mục 3; breakpoint 768px (Tailwind `md:`).
- Sửa mục 9: thay câu "không cần responsive desktop" bằng "desktop ≥768px theo mục 10".

## 2. Sửa workflow build — `.zcode\workflow-drafts\Xây-app-Sổ-học-TOEIC.dwf.ts`
- **Scaffold (`khoi-du`)**: thêm yêu cầu — `AppLayout` responsive (TabBar <768px / Sidebar ≥768px, cùng nguồn dữ liệu menu), hook `useHotkeys` dùng chung, e2e smoke thêm case desktop viewport 1440×900 (sidebar hiện, tab bar ẩn) bên cạnh case mobile 390×844.
- **`dev-hom-nay`**: Home 2 cột theo mục 10 (mobile không đổi).
- **`dev-so-tay`**: trang từ vựng + lỗi sai có chế độ master-detail 2 cột trên desktop.
- **`dev-thong-ke`**: lưới 2 cột biểu đồ trên desktop.
- **`dev-he-thong` / `dev-hoc-thong-minh`**: Cài đặt + Chat cột giữa; SuggestionCard đặt vào cột phải của Home desktop.
- **`ra-soat-tinh-nang`** (reviewer): thêm checklist desktop — sidebar đúng ở ≥768px, không tràn ngang ở 1440px, master-detail hoạt động, phím tắt bỏ qua khi đang gõ.
- **`tac-gia-tai-lieu`** (README): thêm mục "Dùng trên máy tính" (cài PWA desktop, phím tắt, lưu ý dữ liệu theo trình duyệt).

## 3. Khởi động lại build
Gọi `AmendWorkflow` cho run `dwfrun-906bcfc2` với script đã sửa → run mới bắt đầu từ đầu (run cũ chưa kịp làm gì nên không có gì để tái sử dụng). Khi xong tôi sẽ nhận thông báo và tóm tắt kết quả.

**Lưu ý:** duyệt plan này = đồng ý khởi động lại workflow build (chi phí tokens tương đương lần trước, cộng thêm phần desktop). Nếu bạn muốn chỉnh script xong nhưng tự tay bấm chạy sau, nói tôi tách bước 3 ra.
